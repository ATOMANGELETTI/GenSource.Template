# plans/

Saved or templated plans for recurring work — reusable planning skeletons,
distinct from a one-off plan generated for a single task.

- **Naming**: `<name>-plan-template.md` for reusable templates, or
  `<date>-<topic>.md` for saved historical plans worth keeping.
- **Content**: a plan structure (sections, checklists) that's used often
  enough to template, e.g. "add a new Tauri command" or "add a new page."

No plan templates exist yet.
